# 📊 Real-Time Market Analytics Dashboard

A real-time cryptocurrency market analytics dashboard built using Python, Streamlit, Pandas, Plotly, and Binance API.

## 🚀 Features

- 📈 Real-time cryptocurrency price
- 💰 24-hour price change
- 🔺 24-hour high and low
- 📦 Trading volume
- 📊 Candlestick price chart
- 📉 Moving Average (MA20)
- 📉 RSI technical indicator
- 🧠 Market trend detection
- 🔥 Top gainers and losers
- 🔄 Automatic data refresh
- 📥 CSV data download
- 📋 Detailed market data

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Binance REST API
- Technical Analysis (`ta`)
